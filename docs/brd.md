# 业务需求文档（BRD）

> 项目：京东充电桩安装费用核对平台
> 使用方：京东业务侧（约 20 人，内网使用）

## 1. 业务背景

当前各服务商的费用记录方式各异、口径不一：

- **城南安装**：采用领退料方式记录
- **远程机电**：采用分段工程方式记录
- **安家安装**：采用 Excel 方式记录

这些记录方式与京东的收费拆分标准不一致，导致业务人员需要**人工跨表核对**，效率低、且核对过程与结果**无留存**。

## 2. 典型案例

> 同一笔安装：
> - 京东账单金额 **660 元**
> - 服务商申报金额 **720 元**

差异来源：服务商单独列了「额外搬运 60 元」，但按合同约定此项已包含在基础安装费用中。经核对驳回后，双方金额达成一致。

## 3. 京东标准费用项（全局固定）

| 费用项 | 计费方式 | 说明 | 类型 |
| --- | --- | --- | --- |
| 基础安装 | 固定费用 | 含入场搬运；合同基础费已含 | 基础项 |
| 桥架综合施工 | 单价/米 × 距离 | 含材料、配件、安装 | 增项 |
| 电缆穿管 | 单价/米 × 距离 | — | 增项 |
| 断路器安装 | 固定/个 | — | 增项 |
| 其他增项 | 据实填写 | 需审批 | 增项 |

> 该标准库为全局固定，由 admin 角色维护（见 AGENTS.md）。

## 4. 功能范围（In Scope）

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F01 | 服务商管理 | 维护服务商基础信息 |
| F02 | 工单管理 | 管理安装工单 |
| F03 | 服务商链接提交费用明细 | 服务商无需账号，通过工单链接提交费用明细 |
| F04 | 费用核对工作台 | 自动映射标准 + 人工确认 |
| F05 | 结算账单 | 留存、导出 PDF、发送链接 |
| F06 | 数据看板 | 费用与结算数据可视化 |
| F07 | 标准费用库管理 | 维护全局固定的京东标准费用项 |

## 5. 功能范围（Out of Scope）

- 不对接物流调度系统
- 不对接 C 端数据
- 不做移动端
- 服务商无账号体系
- 不做安装进度追踪

## 6. 成功标准

- 核对一笔费用从 **30 分钟** 降至 **5 分钟**
- 所有核对记录**可追溯、可留存**
