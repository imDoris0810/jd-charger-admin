## 一、交互缺陷根因与修复

### 缺陷 1 · 左侧一级导航无法点击（用户报告）

| 项 | 内容 |
| --- | --- |
| **根因** | 导航项**从未绑定任何点击事件**。`prototype.html:22-42` 的 `<button class="nav-item" data-page="...">` 没有 `onclick`；`prototype.js` 中 `.nav-item` 只出现在 `setRole`（显隐）与 `go`（active 样式）两处 |
| **排除项** | 非 z-index、非遮挡、非 pointer-events、非事件冒泡、非 disabled 误判。`document.elementFromPoint()` 命中测试显示 5 个导航按钮中心点命中的都是按钮自身 |
| **漏检原因** | 此前全部测试通过 URL hash 直接访问，**从未真实点击**过导航 |
| **修复位置** | `prototype.js` — 在 `document.addEventListener('click', ...role-menu...)` 之后新增 document 级**事件委托**，单次绑定、不随 DOM 重建失效；并补 Enter/Space 键盘可达 |
| **附带** | `setRole` 中给无权限项补 `disabled` + `title`，说明「当前角色（X）无「Y」权限」 |

### 缺陷 2 · 面包屑「看起来可点但没反应」

`renderCrumb` 渲染的 `.node.done` 有 `cursor:pointer` 但无绑定。
**修复**：已过节点可点击 → 打开对应节点记录（节点 0 → 原始文件，节点 1 → 处理过程与版本），支持 Enter 键。

### 缺陷 3 · TDZ 缺陷第三次复发

`STAGE_NEXT` / `SCENARIO_BIZ` 声明在 init 块之后（行 2561 / 2628），导致 URL 加载时 L4 推荐动作区空白、AI 草稿业务名失效。
**修复**：移至顶部状态区，并做**系统性扫描**确认 init 块之后不再有顶层 `const`/`let` 声明（历史复发记录：`W5_CONFIG_ID` → `STAGE_SCENARIO` → `STAGE_NEXT`/`SCENARIO_BIZ`）。

### 缺陷 4 · W5 AI 建议取字段名错误

`aiSuggestions` 是 M6 遗留实现，字段名用 `missing` 而非 `gaps`，新代码按 `gaps` 取值导致 W5 整块抛错空白。
**修复**：统一字段名，并把筛选口径从「表里没有才建议」改为「**未被人工采纳即建议**」，使待决行也能拿到建议。

### 缺陷 5 · 动作卡 7px 内部溢出（1280px）

`.ag-card` 加 `min-width:0` + `overflow-wrap`，1440 以下收紧间距。

## 二、体验优化

| 页 | 优化 |
| --- | --- |
| **L1** | ① **最优先事项移到五动作分组之前**，进入首屏<br>② 数量为 0 的分组由大卡**压缩为一行芯片**（`待我补充 0`），零卡不隐藏<br>③ 非零卡保留完整形态：名称 + 数量 + 一句任务解释 + 最紧急事项 + 主按钮 |
| **L1/L2** | 「等待对方」类任务按钮由「进入处理 / 进入画布」改为 **「查看进展」**，只允许查看与催办；同时保留禁用态「等待 XX」 |
| **L2** | 主按钮使用**任务专属文案**（数据层新增 `primaryAction`，共 9 条）：`补充桥架计量依据`、`复核照片计量结果`、`确认京东接收要求`、`确认差异处理意见`、`补充合同依据`、`核对拆包记录与单价` 等 |
| **L4** | 中栏顶部新增**当前推荐动作区**：现在做什么 / 为什么 / 缺少什么（含「证据不足」灰标签）/ 时效 / 完成后进入哪一步 / 主操作按钮 + 次级「查看处理过程」 |
| **W5** | AI 映射建议**嵌入对应映射行内**（`.ai-inline`），行内支持 **查看依据 / 采纳 / 修改 / 拒绝 / 补充依据**；表中尚无该字段时以「建议新增映射」提议行呈现；**删除页面底部独立 AI 大区块** |
| **W6** | 五类差异由 5 张大卡**压缩为一行可点击筛选标签**（`无法对应 3` / `金额差异 1` …），带「清除筛选」；下方直接是待对账数据（工单父级 + 一行一个差异对象） |
| **全局** | **中文优先**：`merge` → 合并计算、`unit_price` → 按单价换算、`direct` → 直接对应、`unable_to_map` → 无有效映射；原值降为次级小字（`.tech`，等宽字体） |
