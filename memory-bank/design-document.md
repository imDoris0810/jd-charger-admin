# 设计决策文档（design-document）

> 项目：京东充电桩安装费用核对平台
> 更新日期：2026-09-13
> 状态：已确认（Step 5）

## 1. 背景与目标

京东充电桩安装业务中，各服务商费用记录方式各异（城南安装·领退料 / 远程机电·分段工程 / 安家安装·Excel），与京东收费拆分标准不一致，业务人员需人工跨表核对，效率低、过程与结果无留存。

平台目标：服务商在线提交费用明细 → 系统自动映射京东标准库核对 → 生成可追溯结算账单，将单笔核对从 **30 分钟降至 5 分钟**。

## 2. 已确认的设计决策

### D1 — 服务商通过工单专属 token 链接提交，无需账号

- **决策**：服务商无需登录、无账号体系，通过工单专属 token 链接（`/submit/{token}`）提交费用明细。
- **理由**：服务商数量多、流动性大，账号体系维护成本高且无必要（AGENTS.md 明确服务商「无账号」）。
- **落地**：`work_orders.submit_token`（UNIQUE，创建工单时生成）；链接为 `/submit/{token}`，访问时校验 token 有效性。

### D2 — 标准费用库全局固定，管理员维护，所有工单共用

- **决策**：京东标准费用项为全局唯一一套，由 `admin` 角色维护，所有工单共用；修改留痕并对历史工单生效。
- **理由**：标准库是核对基准，必须统一口径（BRD「京东标准费用项（全局固定）」）。
- **落地**：`standard_fee_items` 表；不物理删除，用 `is_active=0` 停用（AGENTS.md 禁区：`src/config/schema.ts` 为核对核心，改动需单独确认）。

### D3 — 系统自动匹配 + 人工处理异常项

- **决策**：服务商提交后，系统自动将每条明细映射到标准费用项并生成核对结果；只有异常项才需人工介入。
- **理由**：自动通过项无需人工，聚焦异常项是「30 分钟 → 5 分钟」的关键。
- **落地**：`reconciliation_items` 表（系统自动生成），通过 `standard_item_id` 关联标准项。

### D4 — 五状态核对逻辑

- **决策**：核对明细分为五种状态，人工仅处理「金额差异 / 合同已含 / 未识别」三类。

| 状态（DB 值） | 含义 | 原型标签 |
| --- | --- | --- |
| consistent | 一致 | 一致（绿） |
| merged_consistent | 合并一致（多条提交聚合成一条标准项） | 合并一致（青） |
| amount_diff | 金额差异 | 金额差异（黄） |
| contract_included | 合同已含 | 合同已含（红） |
| unrecognized | 未识别 | 未识别（灰） |

### D5 — `included_in_base_fee` 字段驱动「合同已含」自动判断

- **决策**：当服务商单独列的费用项已被 `standard_fee_items.included_in_base_fee` 标记为「含在合同基础费内」，系统自动将其判定为「合同已含」。
- **落地**：典型案例——服务商单独列「搬运费 60 元」，但合同约定已含在基础安装费中，系统自动标记并提示驳回。

### D6 — 账单生成后锁定服务商提交明细

- **决策**：结算账单生成后，关联的服务商提交明细置 `is_locked=1`，禁止再修改，保证账单可追溯、不可篡改。
- **落地**：`provider_submissions.is_locked`；`settlement_bills.work_order_id` UNIQUE 保证一个工单最多一张账单。

### D7 — 账单三种输出方式

- **决策**：结算账单支持三种输出：
  1. **页面留存**：系统内永久可查（`settlement_bills` 表 + 详情页）。
  2. **PDF 导出**：`pdf_url` 存导出链接，jsPDF 生成。
  3. **复制链接发送**：复制账单链接发送给业务侧。

### D8 — 自动匹配采用硬编码关键词（简化方案）

- **决策**：自动匹配的「已含费用」与「合并映射」不新增配置表，在 Worker 内用硬编码关键词列表实现（如「搬运」→ 合同已含、「桥架」→ 桥架综合施工）。
- **理由**：MVP 阶段标准项数量少（仅 5 项），硬编码简单够用，后续再扩展。
- **落地**：`functions/api/lib/matcher.ts`。

## 3. 关键业务规则（源自 BRD）

- **典型案例**：同一笔安装，京东账单 660 元，服务商申报 720 元，差异 60 元来自「额外搬运」——按合同已含在基础安装中，核对驳回后双方一致。
- **5 项标准费用项**：

| 费用项 | 计算方式 | 类型 |
| --- | --- | --- |
| 基础安装 | fixed（固定费用） | 基础项 |
| 桥架综合施工 | per_meter（单价/米） | 增项 |
| 电缆穿管 | per_meter（单价/米） | 增项 |
| 断路器安装 | per_unit（固定/个） | 增项 |
| 其他增项 | actual（据实填写，需审批） | 增项 |

## 4. 边界（Out of Scope）

- 不对接物流调度系统；不对接 C 端数据；不做移动端；服务商无账号体系；不做安装进度追踪。
